ПУБЛИКАЦИЯ И УСТАНОВЩИК

1. Сначала проверьте финальную версию программы в Visual Studio.

2. Для создания переносимой версии запустите:
   Deployment\publish-win-x64.bat

   Появится папка:
   publish\win-x64

   Это self-contained сборка для Windows x64. На другом компьютере
   не требуется отдельно устанавливать .NET 8.

3. Для создания установщика:
   - установите Inno Setup;
   - откройте Deployment\BlackBoxIdentification.iss;
   - нажмите Compile.

   Готовый установщик появится в папке:
   installer-output

Перед сборкой установщика обязательно сначала выполните публикацию из пункта 2.
