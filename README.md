# Программный комплекс параметрической идентификации модели типа «черный ящик»

Настольное приложение C# WinForms для идентификации ядер Вольтерра первого и второго порядков по входному и выходному сигналам.

## Реализовано

- загрузка Excel `.xlsx` в формате `x,y` или `t,x,y`;
- приведение временной оси к интервалу `[0; 1]`;
- демонстрационный набор данных;
- метод коллокации;
- метод наименьших квадратов;
- базис из многочленов Чебышева;
- коэффициенты первого ядра `A_i`;
- двумерная матрица коэффициентов второго ядра `C_ij`;
- восстановление выходного сигнала;
- RMSE, относительная и максимальная ошибки;
- график невязки;
- график `K1(s)`;
- трехмерная поверхность `K2(s1,s2)`;
- диагональное сечение `K2(s,s)`;
- экспорт результатов в CSV.

## Параметры

- `m` — число базисных функций первого ядра;
- `m1` — число базисных функций второго ядра по `s1`;
- `m2` — число базисных функций второго ядра по `s2`;
- для коллокации число узлов вычисляется автоматически:

  `N = m + m1*m2`.

## Формат Excel

Поддерживаются два простых формата:

```text
x(t) | y(t)
```

или

```text
t | x(t) | y(t)
```

Если времени нет, программа создаёт его как `0, 1, 2, ...`.
